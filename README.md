# 🛡️ IPsecGuard: Enterprise VPN Security Analyzer
**Smart India Hackathon 2026 - Prototype by Team Byte Crews (AISSMS IOIT)**

IPsecGuard is an automated, zero-trust vulnerability detection and compliance risk assessment engine for IPsec VPN configurations. It eliminates human oversight by instantly analyzing `.txt` and `.conf` router files to detect weak ciphers, hashing flaws, and misconfigured access lists.

## ✨ 3 Winning Enterprise Features
1. **🔒 Zero-Trust Local Parsing:** 100% offline execution. No sensitive network topologies or IP addresses ever leave the local machine, ensuring absolute data privacy.
2. **📊 Dual-Role Dashboard:** 
   * **Admin View:** Generates exact, copy-paste ready CLI remediation commands.
   * **CISO View:** Translates vulnerabilities into business risks and threat simulation stories.
3. **⚡ Auto-Remediation & Compliance:** Instantly maps configuration flaws to industry standards and generates immediate fixes, reducing Mean Time to Resolve (MTTR).

## 📋 Compliance Benchmarks Audited
- NIST SP 800-77 (IPsec Security Profiles)
- FIPS 140-2 (Cryptographic Standards)
- CIS Benchmarks (Aggressive Mode & ACL configurations)
